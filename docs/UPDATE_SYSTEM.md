# Curriculum Update System

Fluxo editorial: detectar fonte oficial → registrar mudança → gerar proposta → revisar compatibilidade → atualizar versão → rodar testes → aprovação humana → publicar.

Nunca há publicação automática de conteúdo gerado por IA. `curriculum_sources` guarda tecnologia, URL, versão, data, mudança e status de revisão. O painel administrativo futuro fará o diff e a aprovação.
